## 🏗️ Architecture du Projet

Le projet est divisé en trois applications React distinctes (générées avec Vite) orchestrées par un script global :

1. **Launcher (`/launcher`)** : Hub d'accueil avec une interface élégante permettant de basculer facilement entre les différents projets. Tourne sur le port `5173`.
2. **TaskFlow (`/mon_travail`)** *(TD1)* : Application de gestion de tâches (Single Page) avec suivi de statut (À faire, En cours, Terminé). Tourne sur le port `5174`.
3. **PolyQuiz (`/polyquiz`)** *(TD2)* : Moteur de quiz interactif complet (Système de routage sécurisé, Context API, Hooks personnalisés, Reducers, Page 404). Tourne sur le port `5175`.

---

## 🚀 Démarrage Rapide

Pour lancer **tous les projets en même temps**, placez-vous à la racine du dépôt et exécutez la commande suivante :

```bash
npm install
npm start
```

Ensuite, ouvrez votre navigateur à l'adresse **http://localhost:5173** pour accéder au Launcher et naviguer vers TaskFlow ou PolyQuiz en un clic !
